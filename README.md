# Парсер новостей Hacker News

Этот проект представляет собой консольное приложение на Python для парсинга новостей с сайта Hacker News (https://news.ycombinator.com/). Программа собирает заголовки новостей и их рейтинг, сохраняет данные в базу данных MySQL и предоставляет статистику по количеству новостей за день и среднему рейтингу.

## Структура проекта

- parser.py: Основной файл с кодом, содержащий логику парсинга, работы с базой данных и анализа данных.
- libraryvenv/: Виртуальное окружение, содержащее все необходимые библиотеки Python.

## Требования

- Python 3.8 или выше
- Локально запущенный сервер MySQL с базой данных news_db

## Установка

1. Склонируйте репозиторий:
   ```
   git clone <URL-репозитория>
   cd <директория-репозитория>
   ```

2. Активируйте виртуальное окружение:
   ```
   source libraryvenv/bin/activate  # Для Linux/Mac
   libraryvenv\Scripts\activate     # Для Windows
   ```

   Примечание: Все необходимые библиотеки (requests, beautifulsoup4, pandas, mysql-connector-python) находятся в виртуальном окружении libraryvenv.

3. Настройте MySQL:
   - Убедитесь, что сервер MySQL запущен.
   - Создайте базу данных news_db:
     ```
     CREATE DATABASE news_db;
     ```
   - При необходимости измените учетные данные в parser.py (по умолчанию: user="root", password="itsmyfirstlinux").

## Использование

1. Запустите скрипт:
   ```
   python parser.py
   ```

2. Программа:
   - Соберет заголовки новостей и их рейтинг с главной страницы Hacker News.
   - Сохранит данные в таблицу news базы данных news_db.
   - Выведет статистику:
     - Количество новостей по дням.
     - Средний рейтинг всех новостей.

## Схема базы данных

Программа создает таблицу news в базе данных news_db со следующей структурой:

```
CREATE TABLE news (
    id INT AUTO_INCREMENT PRIMARY KEY,
    title VARCHAR(255),
    score INT,
    date VARCHAR(50)
);
```

- id: Уникальный идентификатор записи.
- title: Заголовок новости.
- score: Рейтинг новости (в баллах).
- date: Дата парсинга (в формате ГГГГ-ММ-ДД).

## Настройка

- База данных: Настройте параметры подключения к MySQL в parser.py (host, user, password, database), если они отличаются.
- URL парсинга: В parser.py можно изменить url для парсинга других страниц Hacker News (по умолчанию парсится главная страница).
- Формат даты: Даты сохраняются в формате ГГГГ-ММ-ДД, но можно изменить формат в функции get_news, если нужно.

## Примечания

- Виртуальное окружение libraryvenv содержит все зависимости, поэтому установка дополнительных библиотек не требуется, если вы не добавляете новый функционал.
- Убедитесь, что сервер MySQL работает и база данных news_db создана перед запуском скрипта.
- Программа парсит только новости с главной страницы Hacker News и может собрать ограниченное количество записей за один запуск (зависит от структуры сайта).
- Если сайт недоступен или структура страницы изменилась, парсер может не собрать данные. В таком случае проверьте URL и классы HTML-элементов в коде.
